# LOKI-Cryptographer

**LOKI** — это надежное и быстрое приложение для шифрования данных на Android, разработанное на платформе **.NET MAUI**.

## Безопасность и Открытый код
Исходный код данного приложения опубликован исключительно с целью **аудита безопасности**. Вы можете лично убедиться в отсутствии скрытых бэкдоров, уязвимостей или скрытой отправки ваших данных. Все криптографические операции выполняются строго локально на вашем устройстве.

## Инструкция по сборке для аудита
1. Клонируйте репозиторий.
2. В папке Emails найдите файл-шаблон настроек почты `SecretTemplate.cs`.
3. Переименуйте его в `Secret.cs` и впишите туда свои любые тестовые данные почты для проверки работы отправки. Локальный класс `Secret.cs` автора скрыт через `.gitignore` ради безопасности личных данных.
4. Скомпилируйте проект через Visual Studio / VS Code.
